Restream
=============

## Description

Restream is a program that allows the user to stream as a mpegts their own files from a directory.  Multiple streams can be set up and running at the same time so that they can be used as TV channels to applications such as Jellyfin, TVHeadend or directly to Kodi.  EPG and playlists are provided via urls.
